1. OBJETIVO
================================================================
Hoje qualquer pessoa escolhe ser aluno/professor/coordenador no Cadastro. 
Isso é inseguro. O correto é:
- Cadastro público cria APENAS aluno (ou nem existe)
- Um ADMIN seedado cria professores e coordenadores (e alunos se quiser)
- Login continua lendo a role das tabelas alunos/professores/coordenadores/admins

3. SOLUÇÃO PROPOSTA (Opção B mantida)
================================================================
- Criar 1 ADMIN seed via SQL + Auth (ex: admin@papp.com / Admin123!)
- Remover o <select role> do Cadastro público. Cadastro público = só aluno.
- Criar tela /admin (protegida) onde só admin logado cadastra: nome, email, senha, cargo (aluno/professor/coordenador/admin)

- RLS: professores/coordenadores/admins só podem ser inseridos por quem já é admin. Alunos pode ser por auto-cadastro OU só por admin (você escolhe).

  -- ALUNOS: permite auto-cadastro OU só admin (escolha 1)
  -- Escolha 1: auto-cadastro liberado (atual) -> mantém alunos_insert_own = auth.uid() = id
  -- Escolha 2: SÓ admin cria alunos (mais seguro) -> troque para:
  --   create policy "alunos_insert_admin_only" on public.alunos for insert with check (
  --     exists (select 1 from public.admins where id = auth.uid())
  --   );

  -- PROFESSORES / COORDENADORES / ADMINS: SÓ admin cria
  drop policy if exists "professores_insert_own" on public.professores;
  create policy "professores_insert_admin" on public.professores for insert with check (
    exists (select 1 from public.admins where id = auth.uid())
  );
  drop policy if exists "coordenadores_insert_own" on public.coordenadores;
  create policy "coordenadores_insert_admin" on public.coordenadores for insert with check (
    exists (select 1 from public.admins where id = auth.uid())
  );
  drop policy if exists "admins_insert_admin" on public.admins;
  create policy "admins_insert_admin" on public.admins for insert with check (
    exists (select 1 from public.admins where id = auth.uid())
  );
  -- select: todos autenticados podem ler (para login resolver role)
  -- já existe "select_all" = true, mantenha
